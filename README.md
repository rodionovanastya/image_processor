# image_processor

Консольное приложение на C++ для применения графических фильтров к изображениям в формате BMP. Работает по принципу фильтров из популярных графических редакторов: можно выстроить цепочку фильтров, и они применятся к изображению по очереди.

Сторонние библиотеки для работы с изображениями не используются: чтение и запись BMP реализованы с нуля на `std::ifstream` / `std::ofstream`.

## Возможности

- Чтение и запись 24-битных BMP-файлов
- Цепочка фильтров с параметрами, применяемых в заданном порядке
- Базовые фильтры: обрезка, оттенки серого, негатив, повышение резкости, выделение границ, гауссово размытие
- Дополнительный собственный фильтр
- Понятные сообщения об ошибках вместо падений на некорректных входных данных

## Поддерживаемый формат изображений

Входные и выходные файлы должны быть в формате **BMP**, а именно:

- 24 бита на пиксель
- без сжатия
- без таблицы цветов
- тип DIB header: `BITMAPINFOHEADER`

Пример подходящего файла есть в разделе «Example 1» [статьи о BMP в Википедии](https://en.wikipedia.org/wiki/BMP_file_format) и в папке `test_script/data`.

> При подготовке собственных тестовых изображений убедитесь, что они сохранены именно как 24-битный BMP.

## Сборка

Требуется компилятор C++ и CMake.

```bash
cmake -B build
cmake --build build
```

В корневом `CMakeLists.txt` описан исполняемый файл `image_processor`.

## Использование

```
image_processor <входной файл> <выходной файл> [-<фильтр 1> [параметры...]] [-<фильтр 2> [параметры...]] ...
```

- При запуске **без аргументов** программа выводит справку.
- Список фильтров может быть пустым: тогда изображение сохраняется без изменений.
- Фильтры применяются **в том порядке, в котором перечислены** в аргументах.

### Пример

```bash
./image_processor input.bmp /tmp/output.bmp -crop 800 600 -gs -blur 0.5
```

Что здесь происходит:

1. Загружается изображение из `input.bmp`.
2. Оно обрезается до размера 800×600 пикселей (берётся верхний левый угол).
3. Переводится в оттенки серого.
4. Применяется гауссово размытие с сигмой 0.5.
5. Результат сохраняется в `/tmp/output.bmp`.

## Фильтры

В формулах каждая компонента цвета — вещественное число от 0 до 1, а цвет пикселя — тройка `(R, G, B)`. Таким образом, `(0, 0, 0)` — чёрный, `(1, 1, 1)` — белый.

| Фильтр | Аргументы | Описание |
|---|---|---|
| Crop | `-crop width height` | Обрезает изображение до заданных ширины и высоты, оставляя верхнюю левую часть |
| Grayscale | `-gs` | Переводит изображение в оттенки серого |
| Negative | `-neg` | Преобразует изображение в негатив |
| Sharpening | `-sharp` | Повышает резкость |
| Edge Detection | `-edge threshold` | Выделяет границы |
| Gaussian Blur | `-blur sigma` | Гауссово размытие |

### Матричные фильтры

Если фильтр задан матрицей, значение каждой цветовой компоненты целевого пикселя вычисляется как взвешенная сумма значений этой компоненты в соседних пикселях. Целевому пикселю соответствует центральный элемент матрицы.

Например, для матрицы

```
1 2 3
4 5 6
7 8 9
```

значение компоненты пикселя `C[x][y]` равно

```
C[x][y] = min(1, max(0,
    1*C[x-1][y-1] + 2*C[x][y-1] + 3*C[x+1][y-1] +
    4*C[x-1][y]   + 5*C[x][y]   + 6*C[x+1][y]   +
    7*C[x-1][y+1] + 8*C[x][y+1] + 9*C[x+1][y+1]
))
```

**Края изображения.** Если часть матрицы выходит за границу изображения, для вышедших пикселей берётся значение ближайшего к ним пикселя изображения.

### Описание каждого фильтра

**Crop** (`-crop width height`)
Обрезает изображение до заданных ширины и высоты, используется верхняя левая часть. Если запрошенные размеры превышают размеры исходного изображения, возвращается доступная часть.

**Grayscale** (`-gs`)
Переводит изображение в оттенки серого:

```
R' = G' = B' = 0.299 R + 0.587 G + 0.114 B
```

**Negative** (`-neg`)
Переводит изображение в негатив:

```
R' = 1 - R,  G' = 1 - G,  B' = 1 - B
```

**Sharpening** (`-sharp`)
Повышает резкость применением матрицы:

```
 0 -1  0
-1  5 -1
 0 -1  0
```

**Edge Detection** (`-edge threshold`)
Выделяет границы. Изображение переводится в оттенки серого, затем применяется матрица:

```
 0 -1  0
-1  4 -1
 0 -1  0
```

Пиксели со значением больше `threshold` окрашиваются в белый, остальные — в чёрный.

**Gaussian Blur** (`-blur sigma`)
Гауссово размытие, параметр — сигма. Вес соседнего пикселя `(x, y)` при вычислении значения пикселя `(x0, y0)` определяется гауссовой функцией:

```
w(x, y) = 1 / (2πσ²) · exp( -((x - x0)² + (y - y0)²) / (2σ²) )
```

Существует несколько вариантов реализации и оптимизации этого фильтра (например, использование разделимости ядра на две одномерные свёртки), см. [описание в Википедии](https://en.wikipedia.org/wiki/Gaussian_blur).

## Архитектура

Программа разбита на независимые универсальные компоненты, не привязанные к специфике задачи:

- **Цвет** — класс, представляющий цвет пикселя.
- **Изображение** — класс, обеспечивающий хранение пикселей и доступ к ним.
- **Чтение и запись BMP** — отдельные классы (или функции) для загрузки из BMP и сохранения в BMP.
- **Фильтры** — иерархия классов с общим базовым интерфейсом; общие части (например, применение матрицы) вынесены в промежуточные базовые классы.
- **Контроллер** — разбирает аргументы командной строки, создаёт цепочку фильтров и последовательно применяет её к изображению.

## Обработка ошибок

Все исключительные ситуации обрабатываются через механизм исключений, пользователю выводится понятное сообщение об ошибке. Программа не должна падать, в частности, при:

- файлах, формат которых не соответствует спецификации;
- несуществующем входном файле или недоступном выходном пути;
- неизвестных фильтрах;
- фильтрах с некорректным числом или значениями аргументов.
